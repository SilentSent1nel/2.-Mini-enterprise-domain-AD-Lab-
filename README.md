# Mini Enterprise Domain & Active Directory Lab #

Een kleinschalige enterprise omgeving waarin een Windows Server als Doimain Controller, Windows Client en Ubuntu Client worden ingericht en met elkaar samen werken.

## Projectstatus

**Status:** Afgerond
**Startdatum:** 31-7-2026
**Einddatum:** 15-8-2026

## Doel van het project ##

Het doel van dit lab is het opzetten en documenteren van een kleine enterprise omgeving met in iedergeval:
- Windows Server als Domain Controller
- Active Directory Domain Services (AD DS)
- DNS
- Windows Client als domain member
- Ubuntu Client als domain member
- Group policies
- Communicatie tussen systemen
- File sharing
